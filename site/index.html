What it actually does

Graphs ⇄ scripts, one document

Every KHR_interactivity behavior graph is also real, readable TypeScript-flavored code — edit either view and the other stays in sync. An EQUIV badge proves graph and script describe the same behavior, not two drifting copies.

Everything is glTF

Scenes, materials, audio, and a complete game's worth of logic all live inside one .glb. The R4 Racer sample — steering, laps, an AI rival, a finish sequence — is a real playable game in about 100KB, no separate engine project.

Play in-editor, two engines

Press play and run the graph right there — either a reference interpreter or a graph-to-JS compiled engine, side by side for parity. Export writes a portable .glb that runs in any conformant engine.
